        Kirim kunci API dari browser?

        Pertanyaan dan kunci dikirim langsung dari browser Anda ke:

          Halaman ini tidak punya server; kunci tidak disimpan atau dicatat dan hilang saat tab ditutup. Namun kunci yang dipakai di browser lebih berisiko daripada di skrip lokal. Gunakan kunci khusus untuk audit ini dengan batas biaya, lalu cabut setelah selesai.

          Bantuan

          Cara memakai

          1. Audit baru: aktifkan model, tempel kunci API, atur bahasa dan topik, klik Jalankan audit. Hasil muncul langsung saat jawaban masuk.
          2. Impor: buka responses.csv atau dashboard_data.json hasil versi CLI, .exe, Colab, atau Streamlit.
          3. Fokus analisis: ganti destinasi fokus dan pembanding kapan saja; semua angka dihitung ulang seketika.

          Metrik

          Share of AI voice
          sebutan destinasi dibagi total sebutan semua destinasi.
          Mention rate
          persentase jawaban yang menyebut destinasi minimal sekali.
          Urutan pertama
          posisi rata-rata destinasi saat pertama disebut (1 = paling awal).
          Per 100 sebutan
          untuk setiap 100 sebutan pembanding, berapa kali destinasi fokus disebut.

          Keamanan

          • Tidak ada server: semua perhitungan berjalan di browser Anda.
          • Kunci API hanya di memori tab, tidak pernah disimpan ke penyimpanan browser, tidak masuk file ekspor, dan dibersihkan saat halaman ditutup.
          • Koneksi dibatasi oleh Content Security Policy hanya ke endpoint resmi provider; redirect ditolak.
          • File impor diproses lokal dan ditampilkan sebagai teks biasa. Ekspor CSV aman dibuka di Excel (formula dinetralkan).
          • Untuk pemakaian rutin atau tim, jalankan versi CLI, .exe, atau Colab agar kunci tetap di komputer Anda.
