Cara pakai

  1. Google Colab: buka gem_visibility_auditor.py di GitHub, salin seluruh isinya ke satu sel Colab, lalu jalankan. Simpan kunci API di Colab Secrets (ANTHROPIC_API_KEY, GEMINI_API_KEY, OPENAI_API_KEY).
  2. Windows .exe: unduh GEM-Visibility-Auditor.exe dari halaman Releases, klik dua kali, ikuti wizard. Build sendiri: pyinstaller --onefile --name GEM-Visibility-Auditor gem_visibility_auditor.py
  3. Python lokal: pip install -r requirements.txt lalu python gem_visibility_auditor.py --models anthropic gemini openai
  4. Dashboard Streamlit: streamlit run streamlit_app.py atau deploy ke Streamlit Community Cloud.
  5. Hasil (responses.csv / dashboard_data.json) bisa diunggah ke halaman ini.
GEM Visibility Auditor. Metode: hitung sebutan alias destinasi (mis. "Lake Toba", "Samosir") di setiap jawaban, share of voice = sebutan destinasi / total sebutan.
